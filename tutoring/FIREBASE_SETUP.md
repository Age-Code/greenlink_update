# StudyTogether Firebase setup

The app uses Firebase Authentication and Cloud Firestore. Firebase platform files
are configured for project `tugether-a3dea`; repeat `flutterfire configure` only
when changing the Firebase project or adding a platform.

## 1. Install packages

This repository is pinned to Flutter 3.29.3 / Dart 3.7.2. Do not run a major-version
upgrade. From the project root:

```bash
flutter pub get
```

## 2. Enable sign-in providers

Email/Password is enabled and deployed from `firebase.json`. In Firebase Console,
open **Authentication > Sign-in method** to configure optional social providers:

- Google
- Apple (only if Apple sign-in will be shipped)

For Android Google sign-in, register the debug/release SHA fingerprints. For iOS,
keep the `REVERSED_CLIENT_ID` URL scheme generated by FlutterFire in
`ios/Runner/Info.plist`.

## 3. Firestore

The default Firestore Native database is created in Seoul (`asia-northeast3`). Deploy
the checked-in rules after changing them:

```bash
firebase deploy --only firestore:rules,firestore:indexes
```

The current rules only allow an authenticated user to create, read, and update
their own `users/{uid}` profile. Class, note, quiz, and review access remains closed
until those features and their rule tests are implemented.

## 4. Run

```bash
flutter run -d chrome
flutter run
```

To build and deploy the web app:

```bash
flutter build web
firebase deploy --only hosting
```

Firebase Hosting is configured to send every SPA route back to `index.html`, so
directly opening `/login`, `/role-selection`, or `/home` works after deployment.

The implemented flow is onboarding, authentication, role selection, and a
responsive home backed by preview class data.

## Troubleshooting

- `operation-not-allowed`: enable the selected authentication provider.
- `permission-denied` while selecting a role: deploy the checked-in Firestore rules.
- Google `unauthorized-domain`: add the web host under Authentication settings.
- iOS Google sign-in does not return: verify the reversed client ID URL scheme.
- Apple sign-in fails: configure the Apple provider, Service ID, key, and platform
  capabilities in Firebase and the Apple Developer portal.
